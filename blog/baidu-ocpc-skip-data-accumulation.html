Baidu oCPC Now Supports Skip Data Accumulation on All Traffic Types

📊 The Data Dilemma

When you launch a new Baidu search campaign with oCPC (Baidu's smart bidding system), the platform puts you through a "data accumulation" phase. The algorithm needs to observe your conversion patterns before it can start optimizing bids automatically.

For overseas B2B brands, this is a real problem. If your campaign generates one or two conversions a day, the learning phase can drag on for weeks -- all the while, you are paying per click without smart optimization.

Baidu gets this. As of late 2021, the "skip data accumulation" toggle is now available for all traffic types -- desktop traffic included. Previously, only mobile campaigns had this option.

⏰ ⏰ When to Use It -- And When Not To

💡 Pro Tip: Skip data accumulation if your campaign generates steady conversions. If you see fewer than 20 conversions per week, let the algorithm learn first -- jumping in too early can cause performance swings.
Good candidates for skipping:
  • Established campaigns with predictable conversion rates
  • Click bid coefficient mode (zero downside)
  • Time-sensitive promotions where you cannot wait for learning
Better to let oCPC learn:
  • Brand-new campaigns with zero conversion history
  • Niche B2B keywords with <1 conversion per day
  • When daily performance stability is critical
