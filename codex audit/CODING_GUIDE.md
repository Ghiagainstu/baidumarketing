# BPP Website Coding Guide for Codex

## Project Overview
- **BPP (Baidu PPC Pro)**: B2B marketing website helping overseas companies enter China's Baidu advertising market
- **Domain**: baidumarketing.com
- **Tech Stack**: Pure HTML/CSS/JS, no frameworks
- **Pages**: index / features / pricing / clients / faq / contact / blog / privacy / terms / about / why-baidu-ppc-pro / china-geo (12 pages) + 41 blog posts under blog/

## Deployment
- **GitHub**: https://github.com/Ghiagainstu/baidumarketing.git (private repo)
- **Hosting**: Vercel (migrated from Netlify)
- **Deploy Flow**: `git push` → GitHub → Vercel auto-deploy
- **Vercel Config (vercel.json required)**:
  - `"buildCommand": null` — prevents Vercel from trying to build
  - `"installCommand": null` — prevents Vercel from running npm install
  - `"outputDirectory": "."` — explicitly set output to root (⚠️ without this, Vercel deploys empty project, all 404)
  - `"cleanUrls": true` — removes .html extension

## Critical Rules

### URL Format
- **Internal links must use clean URLs**: `/features` not `/features.html` (.html triggers 308 redirect)
- **All URLs must include `www`**: canonical / hreflang / x-default / OG URL / sitemap use `https://www.baidumarketing.com/`
- **No `.html` in sitemap**: sitemap `<loc>` and `<xhtml:link>` cannot contain `.html`

### Navigation
- **Mobile nav `nav-mobile-cta`**: `Get Started →` button **only on index.html**
- **Last nav link**: must be `<a href="contact">Contact</a>`, not `nav-mobile-cta` class
- **Nav order**: Why Baidu PPC Pro → Services → Pricing → Clients → FAQ → About → Blog → Contact

### SEO Requirements
- **Canonical**: absolute URL with `www`
- **OG tags**: 6 items (title, description, image, url, type, site_name)
- **Twitter Card**: 4 items (card, title, description, image)
- **JSON-LD**: WebSite+Organization on homepage, FAQPage on FAQ, BlogPosting on blog posts, WebPage on core pages
- **GA4**: Measurement ID `G-TCGE7NJT7H`, insert after `<head>`
- **Title format**: `Title — Baidu PPC Pro` (30-70 chars), Blog: `Title — Baidu PPC Pro Blog`
- **theme-color + color-scheme**: required on all pages

### Styling
- **Footer**: `background: var(--gray-800); color: #D1D5DB;` (dark style, consistent with homepage)
- **Favicon**: inline SVG must use single quotes only (double quotes break HTML attributes)
- **Footer wrapper**: no `<div class="container">` needed (footer-top has max-width:1140px)
- **theme-toggle CSS**: must include `.theme-toggle svg { width: 18px; height: 18px; }` + hover rotate + dark mode icon switch

### Form Handling
- **Contact forms**: use `handleSubmit()` with `window.location.href = 'mailto:...'` (Netlify forms don't work on Vercel)

### Copyright
- **Dynamic year**: `document.write(new Date().getFullYear())`
- **Footer "About Us" link**: non-homepage → `about`, homepage → `#whyus`

## Multi-Language Architecture
- **Structure**: subdirectory + build script
  - `baidumarketing.com/` - English (default)
  - `baidumarketing.com/ja/` - Japanese
  - `baidumarketing.com/ko/` - Korean
- **Translation JSON**: `locales/nav-{lang}.json`, `locales/footer-{lang}.json`, `locales/languages.json`
- **Build script**: `build.mjs` - manages nav sync, sitemap updates, page listing
- **Language switcher**: top-right of nav (flag dropdown) + footer text links
- **Priority**: Japanese (Phase 1) → Korean/German (Phase 2) → Spanish/French/Vietnamese (Phase 3)
- **Translation method**: AI translation, English as source
- **SEO**: hreflang tags, per-language canonical, localized OG tags

### Build Commands
```bash
node build.mjs sync all    # Sync all language nav/footer
node build.mjs ls          # List all page status
node build.mjs site        # Update sitemap.xml
```

## Common Pitfalls
1. **git push proxy**: Check `.git/config` for old proxy `http://127.0.0.1:10808`, remove with `git config --local --unset http.proxy`
2. **build.mjs baseURL**: Always verify `www` is included after changes
3. **JA/KO blog CSS**: Must include `.container` rule (EN doesn't have it but JA/KO needs it)
4. **JA/KO blog**: No `nav-mobile-panel`, no English nav text leaking, must have breadcrumbs
5. **CTA links**: Use `/contact.html` not `/`
6. **takeaway-box strong**: Use `color: #fff` not `opacity: .85`

## Workflow for Changes
1. Edit HTML/CSS/JS files directly
2. Test locally if possible
3. `git add . && git commit -m "description" && git push`
4. Vercel auto-deploys within ~1 minute
5. Verify on https://www.baidumarketing.com/
