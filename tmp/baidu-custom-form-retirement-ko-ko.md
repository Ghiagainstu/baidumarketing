# 바이두, 커스텀 폼 광고 소재 구성요소 종료 — 광고주가 알아야 할 사항

바이두는 정기적으로 성과가 낮거나 오래된 광고 소재 구성요소를 종료한다. 이번 대상은 2024년 7월에 단계적으로 폐기되는 커스텀 폼(自定义表单) 광고 소재 구성요소다.

대다수 광고주에게 이것은 문제가 되지 않는다 — 이 구성요소는 전환율이 낮고 사용자 경험을 해치고 있었다. 그러나 사용 중이었다면, 아래가 대응이다.

## 종료 대상

커스텀 폼 광고 소재 구성요소는 광고주가 검색 광고 내에 직접 폼을 삽입할 수 있는 기능. 사용자는 바이두 검색 결과 페이지를 떠나지 않고 입력·제출할 수 있었다.

바이두의 판단:
- 랜딩 페이지 폼에 비해 전환 가치가 낮다
- 검색 결과 페이지의 사용자 경험 일관성을 해친다
- 다른 광고 소재 유형 대비 성과가 낮다

## 종료 대상 범위

| 구성요소 | 신규 생성 | 기존 표시 | 데이터 리포트 |
|---|---|---|---|
| 커스텀 폼 (自定义表单) | ❌ 7월 26일 중지 | ❌ 7월 31일 중지 | ✅ 27개월 보관 |
| 폼 (表单) | ❌ 7월 26일 중지 | 이미 중지됨 | ✅ 27개월 보관 |

## 영향을 받나?

**아마 받지 않는다.** 이번 종료는 다음으로 제한:
- "커스텀 폼" 광고 소재 구성요소 유형
- "폼" 광고 소재 구성요소 유형

다음에는 영향 없음:
- 랜딩 페이지 폼 (자사 사이트의 폼)
- 리드 폼 확장 기능
- 기타 광고 소재 구성요소 (이미지, 동영상, 전화 확장 등)
- 키워드, 광고 문구, 예산, 입찰 설정

대다수 광고주는 대응 불필요.

## 왜 좋은 소식인가

이러한 구성요소 종료는 플랫폼 건전성의 신호다. 바이두는 저성과 광고 포맷을 적극적으로 제거하여 다음을 개선 중:

1. **검색 결과 페이지의 사용자 경험**
2. **전환 예측 정확도** (불필요한 신호 감소)
3. **잔존 광고 포맷의 품질**

정리하지 않는 플랫폼은 침체된다. 이번 종료는 바이두가 광고 생태계를 적극적으로 관리한다는 증거다.

## 해외 광고주에게 의미하는 것

해외 브랜드에게 이러한 플랫폼 변경은 간과되기 쉽다. 1% 계정에 영향 주는 구성요소 종료의 중국어 발표를 읽지 않는 게 보통이다.

그러나 커스텀 폼에 의존하고 있었다면 — 중국어 랜딩 페이지 구축이 복잡하게 느껴져서였을지도 — 이번 종료는 적절한 랜딩 페이지 구축이 필요함을 의미한다.
