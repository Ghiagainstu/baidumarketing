바이두 클릭 사기 방지, IPv4 차단 추가: 악성 클릭을 막는 방법

📊 바이두에서의 클릭 사기 문제

클릭 사기는 중국 검색 플랫폼에서 현실적이고 지속적인 문제입니다. 경쟁사는 예산을 소진시키기 위해 광고를 클릭합니다. 자동화된 봇은 유료 링크를 통해 랜딩 페이지를 크롤링합니다. 모든 사기 클릭은 비용을 낭비하고 캠페인 데이터를 왜곡합니다——oCPC 알고리즘이 존재하지 않는 사용자에게 최적화되게 합니다.

바이두의 내장 클릭 사기 방지 도구인 상둔(商盾)은 오랫동안 IP 기반 차단을 제공해 왔습니다. 그러나 지금까지는 IPv6 주소만 지원했으며——대부분의 웹사이트(그리고 중국 내 악성 트래픽의 대부분)는 여전히 IPv4에서 실행됩니다.

즉, 보호에 공백이 있었습니다. 중요한 공백이었습니다.

📊 변경 사항 (2020년 12월)

바이두는 상둔의 수동 노출 차단에 IPv4 차단을 추가했습니다. 이제 다음을 차단할 수 있습니다.

  • 개별 IPv4 주소
  • IPv4 주소 범위 (최대 3개 IP 블록)
🛡️
최대 1,000건
통합 차단 한도 (IP + ID + 실시간)
🌐
IPv4 + IPv6
듀얼 프로토콜 지원
⚡
거의 실시간
차단이 수 분 내에 적용
작동 방식:

1. 클릭 데이터에서 의심스러운 IP 식별 (반복 클릭, 무전환, 비정상 패턴) 2. 상둔 수동 차단 목록에 추가 3. 해당 IP는 PC/모바일 모두에서 검색 광고가 표시되지 않음

중요한 제한: 상둔은 사용자가 바이두에 접속할 때의 IP를 기준으로 차단합니다. 바이두의 IPv6 전환(중국 공업정보화부 요청)으로 인해, 사용자가 바이두에는 IPv6로 접속하고 랜딩 페이지에는 IPv4로 접속하는 엣지 케이스가 발생할 수 있습니다. 이 경우 차단이 적용되지 않을 수 있으므로——이러한 공백에는 실시간 IP 클릭 차단을 보완적으로 사용하세요.

📊 해외 브랜드가 직면한 장벽

상둔은 바이두 광고 백엔드 안에 있습니다. 활용하려면 다음이 필요합니다.

1. 바이두 광고 계정 2. 상둔 도구 접근 (중국어 인터페이스) 3. IP 로그의 정기적 모니터링과 사기/정상 관심 패턴 구분 지식

바이두 캠페인을 원격으로 운영하는 해외 팀에게는 IP 로그 분석이 우선순위가 되는 경우가 거의 없습니다——예산이 사라지기 시작할 때까지는요.

📊 BPP가 바이두 예산을 보호하는 방법

🎯 클릭 사기에 대한 BPP의 대책

    • ✅ 매주 바이두 IP 클릭 로그를 모니터링——예산을 소진하기 전에 의심스러운 패턴 식별
    • ✅ 위협 발생 시 상둔 차단 목록을 사전에 유지·갱신——IPv4와 IPv6 모두
    • ✅ 수동 IP 차단과 실시간 클릭 보호를 결합한 다층 방어
    • ✅ 차단된 IP, 추정 절감액, 지속적 위협을 포함한 월간 영문 클릭 사기 리포트 제공
