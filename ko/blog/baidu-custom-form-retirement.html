바이두 커스텀 폼 크리에이티브 컴포넌트 폐지: 광고주가 알아야 할 것

2024년 7월 24일 약 6분 Search Ads Baidu PPC Pro 팀

바이두는 정기적으로 성과가 낮거나 오래된 광고 소재 구성요소를 종료한다. 이번 대상은 2024년 7월에 단계적으로 폐기되는 커스텀 폼(自定义表单) 광고 소재 구성요소다.

대다수 광고주에게 이것은 문제가 되지 않는다 — 이 구성요소는 전환율이 낮고 사용자 경험을 해치고 있었다. 그러나 사용 중이었다면, 아래가 대응이다.

종료 대상

커스텀 폼 광고 소재 구성요소는 광고주가 검색 광고 내에 직접 폼을 삽입할 수 있는 기능. 사용자는 바이두 검색 결과 페이지를 떠나지 않고 입력·제출할 수 있었다.

바이두의 판단:

  • 랜딩 페이지 폼에 비해 전환 가치가 낮다
  • 검색 결과 페이지의 사용자 경험 일관성을 해친다
  • 다른 광고 소재 유형 대비 성과가 낮다

종료 일정

⚠️ 중요 일정
2024년 7월 26일: 커스텀 폼 및 폼 구성요소 신규 생성 중지
2024년 7월 31일: 기존 커스텀 폼 표시 중지. 관리 포털 폐쇄.

종료 대상 범위

영향을 받나?

아마 받지 않는다. 이번 종료는 다음으로 제한:
  • "커스텀 폼" 광고 소재 구성요소 유형
  • "폼" 광고 소재 구성요소 유형
다음에는 영향 없음:
  • 랜딩 페이지 폼 (자사 사이트의 폼)
  • 리드 폼 확장 기능
  • 기타 광고 소재 구성요소 (이미지, 동영상, 전화 확장 등)
  • 키워드, 광고 문구, 예산, 입찰 설정
대다수 광고주는 대응 불필요.

커스텀 폼을 사용 중이었다면

🎯 대응 체크리스트

    • ✅ 활성 커스텀 폼이 있는지 확인 (대부분 광고주에게는 없음)
    • ✅ 있다면, 7월 31일까지 이력 데이터 내보내기
    • ✅ 적절한 랜딩 페이지 폼 설정 — 전환 품질 향상
    • ✅ 데이터 리포트는 종료 후 27개월간 이용 가능

왜 좋은 소식인가

이러한 구성요소 종료는 플랫폼 건전성의 신호다. 바이두는 저성과 광고 포맷을 적극적으로 제거하여 다음을 개선 중:

  • 검색 결과 페이지의 사용자 경험
  • 전환 예측 정확도 (불필요한 신호 감소)
  • 잔존 광고 포맷의 품질
정리하지 않는 플랫폼은 침체된다. 이번 종료는 바이두가 광고 생태계를 적극적으로 관리한다는 증거다.

해외 광고주에게 의미하는 것

해외 브랜드에게 이러한 플랫폼 변경은 간과되기 쉽다. 1% 계정에 영향 주는 구성요소 종료의 중국어 발표를 읽지 않는 게 보통이다.

그러나 커스텀 폼에 의존하고 있었다면 — 중국어 랜딩 페이지 구축이 복잡하게 느껴져서였을지도 — 이번 종료는 적절한 랜딩 페이지 구축이 필요함을 의미한다.

BPP의 대응

BPP 관리 계정은 이미 랜딩 페이지 폼을 사용하고 있으며, 광고 내 폼 구성요소는 사용하지 않는다. 이번 종료는 당사 클라이언트에 제로 영향.

자체적으로 바이두 광고를 운영하며 중국어 랜딩 페이지 구축을 피하려고 커스텀 폼에 의존하고 있었다면 — 지금이 랜딩 페이지 구축 타이밍. 또는 당사에 문의를.
