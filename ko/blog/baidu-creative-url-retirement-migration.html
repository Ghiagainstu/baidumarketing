바이두, 광고 소재 레벨 URL 제공 종료 — 광고주용 이관 가이드

2025년 5월 22일 약 3분 플랫폼 Baidu PPC Pro 팀

플랫폼 이관 작업은 귀찮은 일이다. 하지만 바이두가 URL 관리 시스템의 불필요한 계층을 삭제할 때, 결과는 더 단순한 캠페인 구조가 된다— 이관 기간을 잘 넘기면.

2025년 6월 5일부터, 바이두는 광고 소재 레벨에서 LP URL 설정을 지원하지 않는다. 알아야 할 것과 해야 할 일을 정리한다.

바이두가 이렇게 하는 이유

바이두의 URL 우선순위 시스템은 3계층 구조:

키워드 URL > 광고 소재 URL > 광고 그룹 URL

실제로, 많은 광고주가 동일 광고 그룹 내 모든 광고 소재에 같은 URL을 설정한다. 광고 소재 레벨 URL은 불필요한 계층— 복잡성을증가시키고 가치를 추가하지 않음. 삭제로 플랫폼이 단순화되고 바이두의 클릭→전환 예측 모델 정확도가 향상.

기존 URL 유효, 삭제 가능

어떤 시나리오에 해당하는가?

| 시나리오 | 현재 설정 | 필요한 조치 |

|---|---|---|

| 1 | 광고 소재 URL = 광고 그룹 URL | ✅ 조치 불필요. |

| 2 | 광고 소재 URL = 광고 그룹 URL + 트래킹 파라미터 | ⚠️ 광고 그룹 레벨에서 `{creative}` 와일드카드 사용하여 각 광고 소재 추적. |

| 3 | 광고 소재 URL ≠ 광고 그룹 URL, 그러나 모든 광고 소재에서 동일 URL | ⚠️ URL을 광고 그룹 레벨로 이동. |

| 4 | 각 광고 소재에서 다른 URL | 🔧 재구성: 1제품 = 1 광고 그룹. URL은 키워드 레벨 또는 광고 그룹 레벨에서 설정. |

💡 이관 마감일: 2025년 6월 5일. 이날 이후, 광고 소재 레벨 URL 신규 추가/수정 불가. 기존 URL은 계속 게재되지만 수정 불가— 삭제만 가능. 지금 이관을 시작하여 강제 중단을 피하세요.

6월 5일 이후의 변화

  • ❌ 신규 광고 소재 레벨 URL 추가 불가
  • ❌ 기존 광고 소재 레벨 URL 수정 불가
  • ✅ 기존 광고 소재 레벨 URL 삭제 가능
  • ✅ 기존 URL은 삭제까지 계속 게재
  • ✅ 광고 그룹 레벨・키워드 레벨 URL 완전 지원

실용적인 이관 단계

  • 계정 점검. 모든 캠페인을 내보내고 각 광고 그룹이 어떤 시나리오에 해당하는지 확인.
  • 시나리오 1 계정: 조치 불필요. 이미 광고 그룹 레벨 URL을 통일적으로 사용.
  • 시나리오 2 계정: 광고 그룹 URL에 `{creative}` 와일드카드 추가. 광고 소재 레벨 URL 필드 없이 광고 소재별 추적 유지.
  • 시나리오 3 계정: 광고 소재 URL을 광고 그룹 레벨로 복사. 이후 광고 소재 레벨 URL 삭제.
  • 시나리오 4 계정: 이것이 가장 대규모 이관. 각 광고 그룹이 1제품 = 1LP를 나타내도록 캠페인 재구성. 예외는 키워드 레벨에서 URL 설정.

해외 광고주에게 의미하는 것

바이두 PPC를 운영하는 글로벌 브랜드에게, 이것은 긍정적인 변화다. 광고 소재 URL은 해외 마케팅 팀을 혼란시키는 불필요한 복잡성이었다. 삭제로:

  • 더 단순한 캠페인 구조. 설정・관리 필드가 1개 감소.
  • 더 좋은 성능 예측. 바이두 모델이 더 깨끗한 데이터获得.
  • 설정 오류 감소. 중복이 줄면 URL 불일치도 줄어.

그러나 이관은 바이두 플랫폼을 이해하고 계정에 접근할 수 있는 담당자가 필요.
