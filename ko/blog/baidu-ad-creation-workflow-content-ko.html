바이두는 2025년 10월 16일에 광고 작성 플랫폼에 3가지 업그레이드를 출시했습니다. 이것은 모든 검색 광고주가 아는 세 가지 고통점을 겨냥합니다: 느린 캠페인 설정, 광고 문구 작성 시 백지 증후군, 불필요한 반려를 초래하는 헤드라인 형식 규칙. 무엇이 바뀌었는지—그리고 해외 광고주가 어떻게 혜택을 받는지—알아보겠습니다.

🚀 업그레이드 1: 간소화된 유닛 생성 워크플로우

바이두에서 광고 유닛(광고 그룹)을 설정하는 것은 여러 중첩된 화면을 탐색하고, 랜딩 페이지를 다시 지정하며, 새 유닛을 어떤 플랜에 연결할지 추측해야 했습니다.

새 워크플로우:

💡
개선된 점:
  • ✅ 유닛 생성 전에 마케팅 목표와 입찰 방법으로 플랜 필터링
  • ✅ 새로운 전용 페이지(사이드 패널이 아님)—더 깨끗한 뷰, 플랜 상태 표시
  • ✅ 유닛 생성 중 크리에이티브 추천 자동 제안
  • ✅ 바로가기를 통해 고급 스타일 접근—별도 탐색 불필요
  • ✅ 랜딩 페이지 설정 간소화—추적 URL 접미사가 필수 필드에서 제거됨

핵심: 클릭 수 감소, 오류 공간 감소, 더 빠른 출시.

🚀 업그레이드 2: 카피 생성 도구가 더 똑똑해짐

바이두의 크리에이티브 편집기 내 "카피 생성" 도구가 이전에 하지 못했던 두 가지를 수행합니다:

1. 컨텍스트 자동 채우기: 시스템이 랜딩 페이지와 캠페인 설정을 읽고 비즈니스 이름, 핵심 판매 포인트, 대상 키워드를 미리 채웁니다. 이 입력을 확인하고 "생성"을 클릭하면 초안을 얻습니다.

2. 더 나은 생성 품질: AI가 이제 산업별 지식과 역사적 고CTR 크리에이티브 데이터를 활용하여 카피를 생성합니다. 이것은 일반적인 템플릿 출력이 아닙니다—귀하의 카테고리에서 실제로 성과를 낸 것을 반영합니다.

1

유닛 또는 크리에이티브 생성 진입 → "카피 생성" 클릭

2

시스템이 랜딩 페이지에서 비즈니스 정보 자동 채우기 → 확인 또는 조정

3

"생성 시작" 클릭 → 초안 검토

4

호버하여 편집(와일드카드 추가, 텍스트 다듬기) → "확인" 클릭하여 삽입

🚀 업그레이드 3: 제목 와일드카드 제한—키워드 와일드카드 최대 1개

광고 구조에 가장 큰 영향을 미치는 변화입니다:

❌ 이전

  • 단일 헤드라인에 최대 2개의 키워드 와일드카드 삽입 가능
  • Buy [Keyword] — Best [Keyword] Supplier
  • 결과: 반복적이고 키워드로 가득 찬 헤드라인

✅ 이후

  • 헤드라인당 최대 1개의 키워드 와일드카드
  • Buy [Keyword] — Best [City] Supplier
  • 별도의 지리적 와일드카드는 여전히 허용
📋
새 규칙:
  • 새 크리에이티브: 키워드 와일드카드 최대 1개. 시스템이 2개 이상의 헤드라인 저장을 방지합니다.
  • 기존 크리에이티브: 이전처럼 계속 표시되지만, 편집 시 1개 와일드카드 제한이 적용됩니다.

이것은 더 깨끗한 헤드라인을 강제합니다. 더 이상 키워드로 가득 찬 제목은 없습니다.

바이두의 광고 플랫폼은 중국어입니다. 모든 클릭, 모든 필드, 모든 툴팁—모두 중국어입니다. 개선은 실질적이지만, 해외 광고주는 직접 사용할 수 없습니다.
