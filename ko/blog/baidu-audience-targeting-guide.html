바이두 오디언스 타겟팅 완벽 가이드: 광고주를 위한 실전 설명서

2019년 10월 15일 약 6분 검색 광고 Baidu PPC Pro 팀

바이두 PPC를 어느 정도 운영해 보신 적이 있다면 다음과 같은 답답함을 느껴보셨을 겁니다. 제대로 된 키워드에 입찰하고 광고도 노출되지만, 트래픽이 전환되지 않습니다. 무관한 사용자가 클릭하고, 예산은 소진되며, CPA(전환당 비용)는 계속 오릅니다.

문제는 키워드가 아닙니다. 키워드만으로는 누가 검색하는지 알 수 없다는 점입니다. 두 사람이 완전히 동일한 검색어를 검색하더라도 의도는 전혀 다를 수 있습니다. 바이두 오디언스 타겟팅은 키워드 타겟팅 위에 사용자 프로필 데이터를 덧붙여 이 문제를 해결합니다. 그렇게 하면 광고가 올바른 검색어뿐만 아니라 올바른 사람에게 도달합니다.

“고품질의 타겟 오디언스는 더 많은 트래픽과 동시에 더 많은 전환을 가져다줍니다.” — 바이두 공식 문서

바이두 오디언스 타겟팅이란?

바이두 오디언스 타겟팅은 바이두의 방대한 사용자 데이터베이스를 활용해 사용자의 신원, 관심사, 검색 이력, 사용 앱 등을 바탕으로 이상적인 오디언스를 찾아냅니다. 오디언스 타겟팅을 키워드 입찰과 결합하면, 시스템은 귀하의 타겟 프로필에 부합하는 사용자에게 광고를 우선 노출합니다.

키워드와 광고 게재 사이에 필터를 하나 추가한다고 생각하시면 됩니다. 키워드는 귀하의 광고가 노출되는 검색어를 결정하고, 오디언스 타겟팅은 그 검색자 중 실제로 광고를 보는 사람을 결정합니다.

4가지 타겟팅 차원

바이두는 오디언스를 정의하는 4가지 주요 방식을 제공합니다. 각 방식은 작동 방식이 다르며, 가장 효과적인 캠페인은 여러 차원을 조합합니다.

1. 피처 타겟팅(인구통계)

가장 직관적인 레이어입니다. 사용자의 신원을 기준으로 사용자를 선택합니다.

  • 성별 — 남성 또는 여성
  • 연령 — 연령대별
  • 관심사 — 바이두는 브라우징 및 검색 행동을 바탕으로 사용자를 25개 이상의 관심사 세그먼트로 분류합니다
💡
관심사 카테고리에는 다음이 포함됩니다. 재테크, 부동산, 여행, 자동차, 교육, 건강, 뷰티, 패션, 게임, 식음료, 비즈니스 서비스, 가전제품 등. 귀하의 제품이 특정 관심사 버킷에 해당한다면, 이를 주요 타겟팅 필터로 사용하세요.

2. 행동 타겟팅(검색 및 브라우징 이력)

오디언스 타겟팅이 진가를 발휘하는 부분입니다. 사용자가 실제로 수행한 행동을 기준으로 오디언스를 정의합니다.

  • 검색 이력 — 특정 키워드를 검색한 사용자를 타겟팅합니다(최대 1,000개 키워드). 지난주에 “산업용 펌프 공급업체”를 검색한 사람이라면, B2B 캠페인에 따뜻한 잠재 고객입니다.
  • 브라우징 이력 — 특정 URL을 방문한 사용자를 타겟팅합니다(최대 1,000개 URL). 경쟁사의 가격 페이지를 방문한 사람이라면, 귀하의 제품을 구매할 가능성이 높은 인마켓 사용자입니다.
✅
전문가 팁: 검색 이력 타겟팅은 바이두에서 가장 활용도가 낮은 기능 중 하나입니다. 대부분의 광고주는 키워드 매칭에만 의존하지만, 관련 용어를 이미 검색한 사용자를 타겟팅하면 키워드 입찰만으로는 얻을 수 없는 의도 우위를 확보할 수 있습니다.

3. 앱 타겟팅(모바일 전용)

모바일 캠페인의 경우, 사용자가 설치한 앱 유형별로 타겟팅할 수 있습니다. 특정 앱을 직접 타겟팅할 수는 없지만, 앱 카테고리는 타겟팅할 수 있습니다.

📱 오피스 및 일상 앱

효율 오피스 교육·훈련 여행·내비게이션 재테크 온라인 쇼핑 뷰티 케어 의료 건강 소셜 커뮤니케이션 뉴스·독서

🎮 게임 카테고리

캐주얼 퍼즐 스포츠 경쟁 액션 슈팅 보드·체스 게임 롤플레잉(RPG) 전략 게임 레이싱 영양·피트니스 코스프레·꾸미기 기타 게임

예를 들어 제품이 모바일 게이머를 타겟으로 한다면, 관심사 및 행동 필터 위에 게임 카테고리 앱 타겟팅을 덧붙여 키워드 타겟팅만으로는 절대 도달할 수 없는 정밀한 오디언스를 구축할 수 있습니다.

4. ID 타겟팅(정밀 리타겟팅)

바이두가 제공하는 가장 정확한 타겟팅 방식이지만, 이미 사용자 데이터를 보유하고 있어야 합니다. 알고 있는 식별자를 업로드하면 바이두가 자사 사용자 데이터베이스와 대조합니다.

ID 유형 설명 적합한 용도
Baidu ID 바이두 계정 ID(로그인 사용자) 기존 고객 리타겟팅
IMEI 안드로이드 기기 ID 모바일 앱 리타겟팅
IDFA iOS 기기 ID iOS 앱 리타겟팅
Cookie ID 브라우저 쿠키 웹 리타겟팅
Phone Number 휴대전화 번호(해시화) CRM 기반 타겟팅
⚠️
중요: ID 타겟팅을 사용하려면 해당 데이터를 이미 보유하고 있어야 합니다. 기존 고객으로부터 사용자 ID나 휴대전화 번호를 수집하지 않았다면, 먼저 피처 및 행동 타겟팅으로 시작한 다음 데이터가 쌓이면서 ID 타겟팅으로 나아가세요.

📋 핵심 요약

  • 바이두 오디언스 타겟팅은 키워드 타겟팅 위에 사용자 프로필 필터를 추가합니다 — 올바른 검색어뿐만 아니라 올바른 사람에게 도달합니다
  • 4가지 차원: 피처(인구통계), 행동(검색·브라우징 이력), 앱(모바일 카테고리), ID(정밀 리타겟팅)
  • 검색 이력 및 브라우징 이력 타겟팅은 트래픽 품질을 개선하는 데 가장 활용도가 낮으면서도 가장 효과적인 도구입니다
  • 최상의 결과를 위해 여러 차원을 조합하세요. 관심사 + 검색 이력 + 앱 카테고리는 강력한 조합입니다
  • ID 타겟팅이 가장 정확하지만, 기존 고객 데이터가 필요합니다

🤔 바이두 트래픽을 더 정확하게 만들 준비가 되셨나요?

오디언스 타겟팅을 올바르게 설정하려면 바이두의 오디언스 데이터 레이어가 키워드 매칭 시스템과 어떻게 상호작용하는지 이해해야 합니다. 제대로 하면 전환당 비용이 눈에 띄게 낮아집니다. 잘못하면 오디언스가 지나치게 좁아져 볼륨을 잃게 됩니다.

Baidu PPC Pro(BPP)는 중국에 진출하는 해외 브랜드를 위해 오디언스 타겟팅 캠페인을 구축합니다. 어떤 관심사 카테고리가 어떤 업종에 매핑되는지, 과도하게 좁히지 않으면서 행동 기반 타겟팅을 구성하는 방법, 그리고 CRM 데이터와 ID 타겟팅을 결합해 정밀 리타겟팅을 수행하는 방법을 잘 알고 있습니다.
