# 百度PPCのROIを計算する方法：海外広告主向けフレームワーク

百度に1円を費やす前に、1つだけ知っておくべきことがあります。成功とはどういう姿か、ということです。

多くの海外広告主は、測定可能なフレームワークを持たずに百度に参入します。「リードがほしい」「売上がほしい」とは思っていますが、リードがいくつ必要か、リード1件あたりいくらが妥当か、キャンペーンが投資から浪費に変わったラインはどこか、といった計算をしていないのです。

このガイドでは、百度PPCキャンペーンの前・中・後に使える具体的なROI計算フレームワークを提供します。

## コアROI計算式

基本的な計算式は他のPPCチャネルと同じです。

**ROI =（百度=（百度広告からの収入 − 百度広告の費用）÷ 百度広告の費用 × 100%**

百度広告に¥10,000を費やし、¥45,000の収入を得た場合、ROIは350%です。

ただし、この計算式は事後的にのみ有効です。キャンペーンを計画し予算を設定するには、ビジネス目標から逆算する必要があります。

## 逆算アプローチ：目標ベースの予算モデル

### ステップ1：目標収入を定義する

百度から月間いくらの収入を得たいですか？市場規模と処理能力に基づいた現実的な目標から始めます。

**例：** B2Bメーカーが百度リードから月間¥200,000（約$27,600 USD）の収入を目指す。

### ステップ2：クローズ率を決定する

百度からのリードのうち、実際に顧客になる割合は？業界によって異なります。

| 業界 | 典型的なクローズ率 | 備考 |
|------|-------------------|------|
| B2B製造業 | 8〜15% | 長い営業サイクル、高額契約 |
| SaaS / ソフトウェア | 15〜25% | 短いサイクル、低い契約額 |
| プロフェッショナルサービス | 10〜20% | 関係性依存 |
| Eコマース | 2〜5% | 高ボリューム、低タッチ |
| 教育 / トレーニング | 5〜12% | 季節変動あり |

**例：** メーカーは百度リードからのクローズ率を10%と見積もる。

### ステップ3：必要リード数を計算する

**必要リード数 = 目標収入 ÷ 平均契約額 ÷ クローズ率**

平均契約額が¥50,000（約$6,900 USD）の場合：
- 必要リード数 = ¥200,000 ÷ ¥50,000 ÷ 10% = **月間40リード**

### ステップ4：リード獲得単価を見積もる

百度特有のベンチマークが重要なポイントです。BPPのクライアントデータに基づく業界別平均値：

| 業界 | 平均CPL（RMB） | 平均CPL（USD） |
|------|---------------|---------------|
| B2B製造業 | ¥50〜150 | $7〜21 |
| SaaS / ソフトウェア | ¥80〜200 | $11〜28 |
| プロフェッショナルサービス | ¥100〜300 | $14〜41 |
| Eコマース | ¥20〜80 | $3〜11 |
| 教育 / トレーニング | ¥30〜120 | $4〜17 |
| 医療 | ¥150〜400 | $21〜55 |

**例：** メーカーのCPL見込みは¥100（約$14 USD）。

### ステップ5：月間予算を設定する

**月間予算 = 必要リード数 × リード獲得単価**

- 月間予算 = 40リード × ¥100 = **¥4,000（約$552 USD）**

これは最低額です。実際には、学習期間を考慮して最初の2〜3ヶ月はこの1.5〜2倍の予算を確保すべきです。

### ステップ6：期待ROIを計算する

**月間広告費：** ¥4,000
**月間リード：** 40
**クローズ率：** 10%
**成約件数：** 4
**平均契約額：** ¥50,000
**月間収入：** ¥200,000

**ROI =（¥200,000 − ¥4,000）÷ ¥4,000 × 100% = 4,900%**

これは非常に高い数値に見えます——そして実際に高いのです。百度でのB2B広告は、クリック単価が契約額に対して低いため、極めて高いROIポテンシャルを持っています。ただし、クローズ率と営業サイクルが大きく影響します。営業チームがリードをクローズできなければ、4,900%のROIは意味をもちません。

## 実際に重要な指標

ROIは主要指標ですが、百度キャンペーンの管理には複数の基盤指標の追跡が必要です。

### クリック単価（CPC）

1クリックあたりの費用。百度では業界によってCPCが大きく異なります。

| 業界 | 検索CPC範囲（RMB） | 検索CPC範囲（USD） |
|------|-------------------|-------------------|
| B2B製造業 | ¥2〜8 | $0.28〜1.10 |
| SaaS / ソフトウェア | ¥5〜15 | $0.69〜2.07 |
| プロフェッショナルサービス | ¥8〜25 | $1.10〜3.45 |
| Eコマース | ¥1〜5 | $0.14〜0.69 |
| 教育 | ¥3〜12 | $0.41〜1.66 |

### クリック率（CTR）

インプレッションに対するクリックの割合。百度の検索広告平均CTRは3〜5%です。2%を下回る場合、広告文またはキーワードターゲティングの見直しが必要です。6%を上回る場合、無関係なクリックに課金されている可能性があります。

### コンバージョン率

クリックからリード（フォーム送信、電話、チャット問合せ）への転換率。業界ベンチマーク：

| 業界 | ランディングページCVR |
|------|---------------------|
| B2B製造業 | 3〜8% |
| SaaS / ソフトウェア | 5〜12% |
| プロフェッショナルサービス | 4〜10% |
| Eコマース | 2〜5% |

### リード獲得単価（CPL）

**CPL = CPC ÷ コンバージョン率**

CPCが¥5、コンバージョン率が5%の場合、CPLは¥100です。

### 顧客獲得コスト（CPA）

**CPA = CPL ÷ クローズ率**

CPLが¥100、クローズ率が10%の場合、CPAは¥1,000（約$138 USD）です。これは顧客1人を獲得するためのコストです。

### 広告費用対効果（ROAS）

**ROAS = 収入 ÷ 広告費**

ROAS 5:1は、¥1の支出に対して¥5の収入を得ることを意味します。百度でのB2Bの場合、健全なROASは通常8:1から20:1ですが、利益率と営業サイクルの長さに依存します。

## 実例：SaaS企業の中国市場参入

現実的な数値で完全な例を見ていきましょう。

**企業：** プロジェクト管理ソフトウェアを販売するヨーロッパSaaS企業
**目標：** 百度から月間50件のトライアル登録
**平均契約額：** ¥15,000/年（約$2,070 USD）
**トライアルから有料へのクローズ率：** 20%

| 指標 | 値 |
|------|-----|
| 目標トライアル数 | 月間50件 |
| 予想CPC | ¥8（約$1.10） |
| 予想CVR | 6% |
| 予想CPL | ¥133（約$18） |
| 月間予算 | ¥6,650（約$917） |
| 予想有料転換数 | 月間10件 |
| 月間収入 | ¥150,000（約$20,700） |
| ROAS | 22.6:1 |

**重要な洞察：** SaaS企業の最大リスクは広告費ではありません——トライアルから有料への転換率です。これが20%から10%に低下すると、ROASは半減します。製品トライアル体験の最適化は、広告キャンペーンの最適化と同様に重要です。

## ROI計算のよくある誤り

### 誤り1：Google広告のベンチマークを使用する

百度のCPCは、中国のB2Bキーワードで一般的にGoogle広告より低価格です。Googleのベンチマークを使用すると、コストを過大見積もり、潜在リターンを過小見積もりします。

### 誤り2：学習期間を無視する

百度キャンペーンの最初の1〜2ヶ月はデータ収集フェーズです。CPLは長期平均の2〜3倍になります。予算をそれに合わせてください。

### 誤り3：すべてのリードを同等に扱う

すべてのリードの価値が同じではありません。工場の調達マネージャーからのフォーム送信は、学生のホワイトペーパーダウンロードの10倍の価値があります。リード品質をセグメント化し、リードソース別に転換率を追跡してください。

### 誤り4：営業サイクルの長さを忘れる

中国のB2B営業サイクルは通常30〜90日です。1ヶ月後にROIを測定すると、マイナスのリターンが表示されます——リードがクローズする時間が経っていないためです。キャンペーンの真のROIを評価するには、少なくとも3ヶ月与えてください。

### 誤り5：代理店手数算入しない

BPPのようなパートナーと連携している場合、総ROIの計算に管理手数料を含めてください。優れた代理店は最適化を通じて自らのコストを上回る価値を生み出します——ただし、計算にはそのコストを含めるべきです。
